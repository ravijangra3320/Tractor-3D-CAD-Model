# 🚜 Tractor 3D CAD Model

A 3D tractor model designed and developed using SOLIDWORKS as a Mechanical Engineering CAD project.

## 📌 Project Overview

This project features a detailed 3D CAD model of a tractor, including the main body, chassis, wheels, axles, and other mechanical components.

## 🛠️ Software Used

- SOLIDWORKS
- 3D CAD Modeling
- Assembly Design

## ⚙️ Key Features

- Complete tractor 3D assembly
- Detailed mechanical components
- Front and rear wheel assembly
- Tractor chassis and body design
- Assembly-based CAD modeling
